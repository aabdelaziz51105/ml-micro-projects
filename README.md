# ML Micro-Projects

Small, self-contained ML projects — real data, no tutorial open, worked from scratch to
practice a technique rather than to build a polished product.

## Projects

- [`goals-scored-vs-wins-gradient-descent/`](goals-scored-vs-wins-gradient-descent/) —
  cost function and batch gradient descent implemented by hand, checked against `sklearn` to
  5 significant figures.
- [`food-delivery-time-prediction/`](food-delivery-time-prediction/) — multiple linear
  regression on 50,000 orders. A residual plot catches a censored target that R², p-values,
  and backward elimination all miss.
- [`player-age-vs-market-value/`](player-age-vs-market-value/) — polynomial regression on
  423,823 Transfermarkt valuations. A model that fits well can still predict nonsense
  *inside* the range of its own training data.

More will be added as they're finished.
